# ⬛ Unificando

**Laboratório de projetos autorais & Inteligência Artificial**

Construímos ferramentas open-source com foco em **privacidade**, **IA na borda** e **boa arquitetura** — de bibliotecas de prompts a plataformas de conhecimento com busca semântica.
