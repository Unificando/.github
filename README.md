# Unificando / .github

> Repositório especial de configuração e identidade da organização
> [**Unificando**](https://github.com/Unificando) no GitHub.

## O que é este repositório?

No GitHub, todo repositório chamado `.github` tem um papel especial dentro da
organização que o possui. O daqui concentra o que é **global** do Unificando —
a identidade da org, o texto exibido na página principal e as convenções que se
aplicam a todos os projetos:

| Conteúdo | Caminho | Finalidade |
| --- | --- | --- |
| Perfil da organização | [`profile/README.md`](./profile/README.md) | Banner de apresentação exibido no topo da página da org no GitHub |
| Documentação deste repo | [`README.md`](./README.md) | Este arquivo |

> **Nota:** como este repositório foi criado público com a opção *"visible to
> anyone"*, o `profile/README.md` aparece para **qualquer visitante** da página
> da organização.
